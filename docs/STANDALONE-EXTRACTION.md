## Runtime assumptions retained

- Care states are reducer-issued and opaque; callers do not synthesize states.
- The Studio stays mounted across Restart; it is never keyed by the run ID.
- The parent owns visibility, reduced-motion, renderer-loss, cancel, and trace boundaries.
- WebGL2 setup is effects-only and fail-closed; server rendering does not prove GPU behavior.
- Care state is memory-only and reload intentionally begins a new run.
