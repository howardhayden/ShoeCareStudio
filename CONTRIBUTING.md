# Contributing

## Licensing of contributions

This proprietary-source repository is not accepting unsolicited code, content,
design, workflow, or data pull requests. Issue reports may be opened without
transferring copyright or granting implementation rights.

A substantive contribution is accepted only after signed written terms give
the Owner the rights needed to use, modify, distribute, and commercialize it
consistently with the repository policy. Opening an issue or pull request does
not by itself transfer or license rights. Do not submit employer-, client-,
school-, team-, or third-party-owned material without documented authority.

Accepted engineering changes must preserve genuine engineering evidence through:
`issue → constraint → design decision → implementation → failed test → correction → verification`.
